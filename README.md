# PORTAFOLIO VIRTUAL PROFESIONAL

## Descripción
Sitio web personal desarrollado como trabajo integrador de **Programación III**.
Presenta información profesional, habilidades y proyectos, integrando **HTML5**, **CSS3** y **JavaScript** para lograr una experiencia responsive e interactiva.

## Tecnologías Utilizadas
- **HTML5** — estructura semántica, formularios y multimedia.
- **CSS3** — Flexbox, Grid, animaciones y diseño responsive.
- **JavaScript (ES6)** — funciones, eventos, arrays, manipulación del DOM y validaciones.
- **Git & GitHub** — control de versiones.

## Funcionalidades Implementadas (Etapa 3 — JavaScript)
- **Archivo JavaScript externo** (`script.js`) vinculado desde `index.html`.
- **Array de proyectos** que alimenta dinámicamente la sección "Mis Proyectos".
- **Buscador en tiempo real** de proyectos (evento `input`).
- **Filtros por tecnología** mediante botones (evento `click`).
- **Validación del formulario de contacto** con mensajes de error (evento `submit`).
- **Manejo de errores** con bloques `try / catch`.
- **Interacción visual** en la lista de habilidades (eventos `mouseover` / `mouseout`).
- **Manipulación del DOM**: creación dinámica de tarjetas, cambio de estilos y clases.
