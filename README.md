# PORTAFOLIO VIRTUAL PROFESIONAL

## Descripción
Este proyecto corresponde a la evaluación de **Desarrollo Web** en Visual Studio Code.  
Se trata de un sitio web estable y responsive, diseñado en **HTML5** y **CSS3**, que presenta mi portafolio profesional y evidencia competencias en el uso de etiquetas semánticas, multimedia y estilos modernos.

## Contenido del Proyecto
* **Estructura semántica completa**: Header, Nav, Main, Footer.
* **Secciones principales**:
  - Inicio con presentación personal y recurso multimedia.
  - Habilidades y cronograma de aprendizaje con tabla compleja.
  - Formulario de contacto funcional.
* **Integración multimedia**: video mediante iframe.
* **Diseño responsive**: Flexbox y Grid para adaptabilidad en distintos dispositivos.
* **Estilos personalizados**: paleta de colores, tipografías de Google Fonts y animaciones CSS.
* **Navegación**: enlaces internos mediante anclas y externos hacia GitHub y redes sociales.

## Tecnologías Utilizadas
- HTML5 (estructura semántica y formularios).
- CSS3 (Flexbox, Grid, animaciones y responsive design).
- Git & GitHub (control de versiones y repositorio).
- SQL Server (mencionado en habilidades).
- Herramientas de diseño y organización académica.

## Cronograma de Aprendizaje
El sitio incluye una tabla con el estado de los módulos:
- **HTML5 Semántico** → Completado ✅  
- **Diseño con CSS** → En curso 🔄  
- **Evaluación Final de Proyecto** → Pendiente ⏳  

## Objetivo
Demostrar competencias en:
- Desarrollo web con estándares modernos.
- Aplicación de buenas prácticas de diseño.
- Integración de recursos multimedia y formularios.
- Presentación académica clara y profesional.
